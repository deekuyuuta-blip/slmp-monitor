# SLMPモニタ（Android）— シンプルCPU通信版

スマホを「SLMP対応機器（QnA互換3Eフレーム）」として待ち受けさせ、R04CPU（iQ-R）の**シンプルCPU通信**でデータをやり取りするアプリです。PLC側はパラメータ設定だけで、ラダーは不要です。

```
R04CPU ──(シンプルCPU通信／SLMP 3E・TCP)──▶ Wi-Fi ──▶ スマホ（このアプリが待受）
  書込み：PLCのデバイス → スマホのデバイス（スマホで表示）
  読出し：スマホのデバイス → PLCのデバイス（スマホで操作）
```

## できること
- PLC→スマホ：PLCが書込んだ値を表示（ワード：符号付き/符号なし16bit、16進、32bit、実数／ビット：ON/OFF）
- スマホ→PLC：スマホで値やビットを変更し、PLCが次の読出し周期で取得
- 操作は「操作ロック解除」中のみ、毎回確認あり
- 通信状態表示（3秒以上要求が来なければ「通信なし」、受信値を灰色表示）
- 通信ログ（PLCからの接続、読出し・書込み、異常）
- ハートビート：指定デバイスを1秒ごとに+1。PLCで読出して監視すれば、スマホ停止を検出できる
- 対応要求：一括読出し 0401／一括書込み 1401（サブコマンド 0000/0001 と iQ-R形式 0002/0003）

## スマホ側
1. PLCと同じネットワークのWi-Fiにつなぐ。**IPアドレスは固定**にする（Wi-Fi詳細設定で静的IP、またはルータでDHCP予約）
2. 「⚙ 設定」を開いて設定し「保存」
   - PLCのIPアドレス：入力すると、そのIPからの接続だけ受け付ける（空欄なら制限なし）。スマホと別ネットワークなら警告を表示
   - 待受ポート番号：シンプルCPU通信設定の交信先ポートと同じにする（例：5000）
   - ハートビート デバイス：1秒ごとに+1するデバイス（空欄でなし）
   - 通信なし判定（秒）：この秒数PLCから要求がなければ「通信なし」表示
   - アプリ起動時に自動で待受を開始
3. 「待受開始」を押す。設定画面とメイン画面に出る「このスマホのIP」を、PLC側の交信先IPに設定する
4. 「＋ 追加」で、シンプルCPU通信設定の交信先デバイスと同じ番号を登録する
   - PLCが書込んでくる範囲 → 「スマホ → PLC」のチェックなし
   - PLCが読出しに来る範囲 → 「スマホ → PLC」にチェック
5. アプリは開いたままにする（画面は自動で消えないようにしています）

## PLC側（GX Works3・R04CPU）
1. ナビゲーション → パラメータ → R04CPU → ユニットパラメータ → 基本設定で、自ノードのIPアドレスを設定（スマホと同じネットワーク）
2. 応用設定 → シンプルCPU通信設定 →「使用する」→ 詳細設定
3. 1行ずつ設定する
   - 交信先の機種：SLMP対応機器（QnA互換3Eフレーム）
   - IPアドレス：スマホのIP、ポート番号：アプリの待受ポート
   - 交信パターン「書込み」：自局（PLC）のデバイス → 交信先（スマホ）のデバイス 例：D0〜D9 → D0〜D9
   - 交信パターン「読出し」：交信先（スマホ）のデバイス → 自局（PLC）のデバイス 例：D100〜D109 → D2000〜D2009、M100〜M115 → M2000〜M2015
   - 交信周期は100〜1000ms程度から
4. 書込み後、PLCをリセット（または電源再投入）

設定画面の項目名はGX Works3のバージョンで多少違うことがあります。正確な手順はMELSEC iQ-R Ethernetユーザーズマニュアル（応用編）の「シンプルCPU通信機能」を確認してください。

## 安全について
- スマホから読出した値は、通信が途切れてもPLC側に**最後の値が残ります**。シンプルCPU通信の交信状態（SM/SD）やハートビートをラダーで監視し、異常時は操作要求を無効にしてください
- スマホからの値で直接出力（Y）を動かさず、要求ビットとしてラダーでインターロックを確認してから動作させてください
- 機械が見えない場所からの起動操作はしないでください
- 工場のネットワークをインターネットへ直接公開しないでください

## 更新について
APKは毎回同じ鍵（`app/slmp-monitor.keystore`）で署名するので、新しい版を上書きインストールできます。
最初の版（1.0）だけは鍵が違うため、1.1を入れる前に一度アンインストールしてください。
この鍵はリポジトリに公開しています（個人利用アプリのための簡易運用）。

## ビルド
GitHubにpushすると GitHub Actions がAPKをビルドし、リリース「latest」に `slmp-monitor.apk` を置きます。スマホのブラウザでそのページを開いてダウンロード・インストールしてください（初回は「提供元不明のアプリ」の許可が必要）。

Android Studio でも開いてビルドできます（Android Gradle Plugin 8.5 / compileSdk 34）。
