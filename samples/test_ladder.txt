=====================================================================
 SLMPモニタ 通信試験用ラダー（FX5U/FX5UC・iQ-R R04CPU 共通）
=====================================================================
 GX Works3 のラダー編集で、1行ずつ命令を入力してください。
 （例：「LD<> D2019 D2018」と打ってEnter）
 ";" から後ろはコメントです。入力しないでください。

---------------------------------------------------------------------
 ■ シンプルCPU通信の設定（交信先：SLMP対応機器＝スマホ）
---------------------------------------------------------------------
 交信先IP：スマホのIP（例 192.168.3.200） ポート：5000
 交信周期：200ms

 設定1  書込み（PLC → スマホ）
   自局 M0〜M15   → 交信先 M0〜M15
   自局 D0〜D19   → 交信先 D0〜D19

 設定2  読出し（スマホ → PLC）
   交信先 M100〜M115 → 自局 M2000〜M2015
   交信先 D100〜D119 → 自局 D2000〜D2019

 アプリ側：「⚙ 設定」→ ハートビート デバイス に D119 を入れる

---------------------------------------------------------------------
 ■ デバイス一覧
---------------------------------------------------------------------
 PLC → スマホ（PLCが作る値）
   M0   運転中
   M1   異常（設定値が範囲外）
   M2   1秒点滅（PLCが動いている目印）
   M3   スマホ通信正常（ハートビートが5秒以内に変化）
   M4   設定値が範囲内（0〜100.0）
   D0   現在値（運転中は0.1秒ごとに設定値へ近づく、小数1桁）
   D1   PLCカウンタ（1秒ごとに+1）
   D2   エコー（スマホのD101をそのまま返す）
   D3   運転回数
   D4   受け取った設定値（D100のコピー）
   D10  32bitカウンタ（D10・D11、0.1秒ごとに+12345）

 スマホ → PLC（スマホで操作する値。PLCでは M2000〜／D2000〜）
   M100 → M2000  運転（押しボタン）
   M101 → M2001  停止（押しボタン）
   M102 → M2002  異常リセット（押しボタン）
   D100 → D2000  設定値（小数1桁、0〜1000 ＝ 0.0〜100.0）
   D101 → D2001  エコー送信値（好きな数字）
   D119 → D2019  ハートビート（アプリが1秒ごとに+1）

 内部
   M3001 ハートビート変化あり   M3002 ハートビート受信済み
   D2018 ハートビート前回値     T0 ハートビート監視

---------------------------------------------------------------------
 ■ プログラム
---------------------------------------------------------------------

; ① ハートビート監視：D2019が5秒変わらなければ M3（通信正常）をOFF
LD<>   D2019 D2018
OUT    M3001
MOV    D2019 D2018

LDI    M3001
OUT    T0 K50          ; 100ms単位で5秒

LD     M3001
SET    M3002           ; 一度でも変化を受けた（電源投入直後の誤判定を防ぐ）

LD     T0
RST    M3002           ; 5秒変化なし → 受信済みを取り消す

LDI    T0
AND    M3002
OUT    M3

; ② 運転・停止：通信正常のときだけ運転できる。通信が切れたら停止
LD     M2000
OR     M0
AND    M3
ANI    M2001
ANI    M1
OUT    M0

; ③ 運転回数
LDP    M0
INC    D3

; ④ 設定値の範囲チェック（0〜1000 ＝ 0.0〜100.0）
LD>=   D2000 K0
AND<=  D2000 K1000
OUT    M4

LDI    M4
SET    M1

LD     M2002
AND    M4
RST    M1

; ⑤ 現在値：運転中は0.1秒ごとに設定値へ1ずつ近づく。停止中は0へ戻る
LDP    SM410
AND    M0
AND<   D0 D2000
INC    D0

LDP    SM410
AND    M0
AND>   D0 D2000
DEC    D0

LDP    SM410
ANI    M0
AND>   D0 K0
DEC    D0

; ⑥ PLCカウンタ・1秒点滅
LDP    SM412
INC    D1

LD     SM412
OUT    M2

; ⑦ エコーと設定値のコピー（スマホ→PLC→スマホの往復確認）
LD     SM400
MOV    D2001 D2
MOV    D2000 D4

; ⑧ 32bitカウンタ（表示の確認用。32767を超える値）
LDP    SM410
D+     D10 K12345 D10

---------------------------------------------------------------------
 ■ 試験の手順
---------------------------------------------------------------------
 1. ラダーとパラメータを書込み、PLCをRUN
 2. アプリで「待受開始」→ 状態が「通信中」、1秒点滅ランプが点滅、PLCカウンタが増える
      → PLC→スマホ OK
 3. 「スマホ通信正常」ランプが点く
      → スマホ→PLC（ハートビート）OK
 4. エコー送信に 1234 を入れる → エコー受信が 1234 になる
      → 往復 OK
 5. 設定値に 50.0 → 「運転」 → 運転中が点き、現在値が 50.0 まで増える
 6. 「停止」 → 運転中が消え、現在値が 0 へ戻る
 7. 運転中にアプリを閉じる（待受停止）→ 5秒後に PLC の M3 がOFF、M0 がOFF（停止）
      → スマホが止まったときの安全動作 OK
 8. アプリを再起動 → 設定値が 50.0 のまま（PLCのD2000が0にならない）
 9. GX Works3 のデバイスモニタで D2000〜D2019 と M2000〜M2002 も見ておくと確実

 ※ 特殊リレー SM400（常時ON）、SM410（0.1秒クロック）、SM412（1秒クロック）は
    FX5・iQ-R 共通です。
 ※ タイマ T0 は初期設定の100ms単位の想定です。
